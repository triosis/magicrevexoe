IV means local contract evidence only, never external certification or full-product completion. IU means the implementation exists but its real external/quality behavior is not verified. N means actual missing code: do not relabel it as only missing credentials. E denotes external evidence/access dependencies. For an explicitly replaced original requirement, IV concerns the amended replacement and does not claim the original behavior exists. D uses the phase column to distinguish Phase 2, Phase 3, explicit Phase 4, Task 02 deferral and ongoing work.
